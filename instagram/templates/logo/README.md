# Profilbild – 3 Varianten

Alle in Markenfarben (`#0B0E14` Hintergrund, `#00E5A0` Akzent, `#FF4D6D` Strike-Level),
als SVG (verlustfrei skalierbar) und als 1080×1080 PNG.
`_uebersicht.png` zeigt alle drei zusätzlich bei **88 / 56 / 32 px** – dem
Größenbereich, in dem sie im Feed und in Kommentaren tatsächlich gesehen werden.

| Datei | Motiv | Aussage | Einsatz |
|---|---|---|---|
| `logo_a_flow` | Volumenbalken → Pfeil | Volumen erzeugt Bewegung | sicherste Wahl, breit verständlich |
| `logo_b_gamma` | Γ (Gamma) als Monogramm | Derivate, Profi-Signal | stärkste Differenzierung, erklärungsbedürftig |
| `logo_c_strike` | Ausbruch über dem Strike-Level | Optionen + Chart in einem Zeichen | **thematisch präziseste Variante** |

**Empfehlung:** `logo_c_strike` – es ist die einzige der drei, die man nicht
sofort in einer beliebigen anderen Finanz-Nische wiederfindet, und die rote
Strike-Linie bleibt auch bei 32 px sichtbar.

**Anpassen:** SVGs sind reiner Text – Farbwerte direkt im `fill`/`stroke` ändern.
Neu als PNG rendern (Chromium ist vorinstalliert):
```bash
node shot.js   # siehe ../README.md
```

**Als Instagram-Profilbild:** PNG hochladen. Instagram beschneidet auf einen
Kreis – die Motive liegen bereits innerhalb des sicheren Kreisbereichs.
